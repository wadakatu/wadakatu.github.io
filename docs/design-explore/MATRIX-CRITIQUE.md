# Matrix prototype critique — Codex

Reviewed and tightened with **Codex**, 13 November 2026, in `design/explore` only. No commit or push.

The concept earns its direction: `_lib.ts` derives rain from the supplied corpus, `_Stream.astro` ties strands
back to individual entries, and `_Records.astro` exposes the same facts. Boot and reversible slab/decode
transitions are substantial, not token decoration. Kept the night phosphor palette, desktop name texture,
operator wall, source routes and rare rewards. No prohibited quotations or film assets found; location remains
Japan. Japanese copy adds distinct information rather than duplicating the adjacent English.

## Findings and changes

- `proto-matrix.js`, `ProtoMatrixLayout.astro`: bare `\` / `¥` had no WCAG 2.1.4 off switch and fired in editable
  fields. Added a labelled footer checkbox, persistent preference, synchronized shortcut metadata/hint, and
  guards for form controls, editable content, IME composition and handled events. The button always works.
- Layout/CSS: head-script success hid the static source link even if enhancement failed. Controls now appear
  only after handlers exist. Skip gets focus independently of the enhancement; storage getters are protected
  against SecurityError. Boot spacing/scrolling keeps Skip reachable on small or short screens.
- Script: reduced motion was read only once. Live changes now finish swaps, clear boot/rewards and stop rain.
  Frozen boot no longer requests GSAP. In-place swaps now update the document title as well as URL/status.
- `matrix.css`: title-to-commit and déjà-vu layers covered subsequent reading text. Confined both to the title;
  long decorative commit snippets clip there. Removed the stretched title-link overlay so body text is selectable.
  Added explicit Japanese heading typography and English language on the commit overlay.
- CSS: strengthened control boundaries using the existing muted colour, preserved dark text on the bright skip
  link during hover, removed illegible name-mask detail below 720px, and delayed the seven-column wall to 1360px
  so intermediate widths use the existing rows. This keeps the concept while improving reading conditions.

## Verification and limits

`npm run build` passed, 42 pages; JS syntax check passed. Playwright/Chrome: four routes × two widths
(1440/390) × two themes, zero horizontal overflow, one visible h1/view, computed text contrast minima
8.68:1 night and 5.61:1 day. Inspected desktop/mobile/day/boot screenshots. Boot, rapid source round trips,
no-JS, CDN failure, focus, shortcut persistence/editable fields/IME, storage denial, missing enhancement and
live reduced-motion checks passed. Existing content and non-target modifications were left untouched.

Not a full accessibility certification: screen readers, Safari/Firefox, low-end performance and pixel-level
contrast in the decorative name mask remain unverified. Chrome DevTools MCP could not connect; browser checks
used installed Playwright/Chrome. Impeccable’s launcher and referenced craft-floor/playbooks are absent in this
worktree. No tools or dependencies were installed. Third-party fonts/GSAP remain; failed GSAP still gives an
instant, usable source switch. Long commit rewards intentionally show only the title-sized fragment.
